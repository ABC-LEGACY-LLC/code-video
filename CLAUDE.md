# code-video

What the Labs workshop found for this project is in `abc-labs/rooms/` (see
`abc-labs/README.md`). At the start of a session run
`npx -y https://labs.abclegacyllc.com/cli.tgz rooms status`; when something is
new, `rooms pull` and read it before deciding. A question for a room's agent:
`rooms ask <n> "…" --wait`.
