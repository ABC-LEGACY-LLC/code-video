Small enough to forget, considered enough to notice.
Every card here plays the cue that tells its own story. Press one.
6.4 kB Tiny No audio files, no dependencies. All fourteen cues in 6.4 kB.
Live Every cue is synthesized with Web Audio the moment it plays. There are no recordings to load.
Declarative One attribute per behavior. Add it to your markup and bind() does the rest.
Curated Fourteen cues, one for each interface job, each with its own shape. Clicks, keystrokes, air, and soft mallets, not fourteen tweaks of one click.
Two lines from silent to alive.
1. Install the package
$ npm install cuelume
Click the command to switch package manager.
2. Mark up and bind
Add an attribute to anything that should make a sound, then call bind()
once at startup.

9 import &lbrace; bind, play, setTheme, setVolume &rbrace; from "cuelume" ;
bind(); // wires every data-cuelume-* attribute
setVolume(0.7); // global loudness, from 0 to 1
setTheme( "mech" ); // dry, precise, mechanical
play( "success" ); // inherits the global volume
play( "success" , &lbrace; volume: 0.4 &rbrace;); // quieter for this play only
play( "success" , &lbrace; emphasis: "strong" &rbrace;); // weightier when it matters
