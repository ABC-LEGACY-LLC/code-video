**Optional Desktop Improvement Data.** The Cardboard desktop app can send product usage data, Director data, and crash
data to help us improve the app. Product usage data does not include project or conversation content. Director data can
include conversation text and visible agent activity, such as filenames, paths, tool inputs, and tool results. Crash
data excludes project and conversation content. Project and media files are not uploaded as telemetry. You can stop
future uploads with the "Share data to improve Cardboard" switch in desktop Settings. This switch is on by default.
Turning it off does not disable Director.
